# Focus Island — Smoke-проверка

Для запуска dev-сборки выполните в корне проекта:

```bash
zsh scripts/launch-dev-app.sh
```

Хуки для интеграции с Claude Code устанавливаются из меню Settings → Setup. Установка хуков модифицирует файл `~/.claude/settings.json`.

Данные приложения хранятся в `~/Library/Application Support/FocusIsland/`.

---

## Чек-лист S1–S23

1. S1: ⌥⌘B → создать по задаче в Backlog/Todo; «+» в island добавляет в Todo; drag & drop между колонками сохраняется после перезапуска.

   ⬜ не проверено
   
   Комментарий:

2. S2: `claude` в новом терминале → чип «Привязать к задаче?»; выбор задачи из Todo переносит её в In progress; в свёрнутом island справа — её заголовок.

   ⬜ не проверено
   
   Комментарий:

3. S3: долгий промпт → через заданное в Settings → Focus время («Через N с», по умолчанию 15 с) карточка «Что дальше?»: сверху «Пока ждёшь — в этой же задаче», ниже «Или переключиться» с задачей из Todo; «Начать» открывает новый терминал в папке проекта и запускает `claude`.

   ⬜ не проверено
   
   Комментарий:

4. S3b: две сессии; вторая просит разрешение, пока первая работает → карточка «Что дальше?» первой сессии в блоке «Или переключиться» предлагает «Ответить <проект> — дело на минуту» с кнопкой «Перейти».

   ⬜ не проверено
   
   Комментарий:

5. S4: во время работы Claude 25 с в Telegram/YouTube → nudge; «Вернуться» переключает в терминал; эпизод в `distraction_episodes`.

   ⬜ не проверено
   
   Комментарий:

6. S5: вкладка «История» → старая завершённая сессия → «Продолжить» → открывается терминал с `claude --resume`, контекст восстановлен.

   ⬜ не проверено
   
   Комментарий:

7. S6: перетащить задачу в Done → на вкладке «Неделя» «Задач закрыто» увеличилось; детали задачи показывают все её сессии.

   ⬜ не проверено
   
   Комментарий:

8. Перезапуск приложения при живой сессии `claude` → сессия остаётся live, чип привязки повторно не появляется.

   ⬜ не проверено
   
   Комментарий:

9. Остановить приложение, поработать с `claude`, запустить снова → новые сессии появились в Истории (backfill).

   ⬜ не проверено
   
   Комментарий:

10. S7: шаги плана. Дать `claude` задачу, по которой он ведёт список TodoWrite → в пульте у работающей сессии полоса прогресса и «Шаг k из n»; на доске у карточки задачи тот же прогресс; после завершения шага счётчик растёт. Без плана вместо шага показывается «Работает · N мин».

    ⬜ не проверено

    Комментарий:

11. S8: очередь промпта. В карточке «Что дальше?» ввести текст в «Следующий промпт» → «Поставить в очередь» (или ⌘↩) → у задачи на доске бейдж «промпт в очереди». Когда Claude закончит, появляется карточка «Claude закончил «<задача>»» с блоком «Промпт в очереди»; «Отправить и вернуться» вставляет текст в терминал и переходит в него. Проверить в Ghostty, iTerm2 и Terminal.app. Для не поддерживаемого терминала — тост «Промпт в буфере — вставь ⌘V» и текст в буфере обмена.

    ⬜ не проверено

    Комментарий:

12. S9: перегрузка. Лимит по умолчанию 3 (Settings → Focus → «Сессии»). Запустить 4-ю живую сессию → карточка «Запускаешь 4-ю сессию» с чипами сессий, блоком «Лучше сначала» («Перейти» / «На паузу») и «Всё равно запустить». «На паузу» убирает сессию в группу «На паузе»; когда слот освободится, тост «Освободился слот — вернуть <проект>?».

    ⬜ не проверено

    Комментарий:

13. S10: отправка в Terminal.app. Запустить `claude` в Terminal.app, поставить промпт в очередь, дождаться завершения хода → «Отправить и вернуться» вводит текст в запущенный `claude` во вкладке этой сессии (искать по tty) и выводит окно на передний план.

    ⬜ не проверено

    Комментарий:

14. S11: ждущие сессии. Оставить сессию в ожидании разрешения дольше порога (Settings → Focus → «Напомнить о ждущей сессии через N мин», по умолчанию 15). Остров сам не открывается и карточки «… легко забыть» нет. Если сессия ждёт ≥ 10 мин, в свёрнутом island правое ухо показывает «<задача> ждёт Nм» оранжевым текстом. Подробности — S23.

    ⬜ не проверено

    Комментарий:

15. S12: начало дня. При включённом «Утренний экран «Начало дня»» первое переключение приложения за день после 05:00 показывает карточку «Доброе утро»: «Вчера осталось открытым», «Твоя заметка с вечера» (из «Завтра начать с» на вкладке «Сегодня»), «Фокус на сегодня» (выбрать 1–3 задачи). «Начать с «<задача>»» переносит выбранные в In progress и открывает сессию. Повторно в тот же день не показывается; вручную открывается из подвала пульта.

    ⬜ не проверено

    Комментарий:

16. S13: подсказка выбора задачи. Без фокусной задачи и без алертов правое ухо свёрнутого island показывает приглушённое «Выбрать задачу · Todo N» (N — задачи в Todo); при пустом Todo — «Доска пуста» (клик открывает доску). Клик по пилюле при непустом Todo открывает карточку «Над чем работаешь сейчас?» со списком Todo (задача проекта с открытыми сессиями первая, с пометкой «N сессий открыто»), кнопкой «Начать» у каждой задачи, «+ Новая задача» и «Доска». «Начать» открывает лист «Начать задачу».

    ⬜ не проверено

    Комментарий:

17. S14: «Начать задачу». Перетащить задачу в In progress на доске (то же из «Начать» в карточке выбора или сменой колонки в карточке задачи) → лист «Начать задачу»: «Задача в работе», «Привязать открытые сессии» (сессии того же проекта отмечены, чужой задачи — с тегом «у задачи «X»» и не отмечены), «Фокус-таймер · необязательно» с сегментами «Без таймера / 25 мин / 50 мин / Своё…» и подписью «потом перерыв N мин». «Начать · 25 мин» делает задачу фокусной, привязывает отмеченные сессии и запускает таймер; «Позже» оставляет задачу в In progress без таймера. Кнопки «Новая сессия Claude» нет. Если перед этим был открыт лист карточки задачи, лист «Начать задачу» всё равно должен появиться. В карточке задачи «+ Добавить сессию» открывает экран выбора (см. S19).

    ⬜ не проверено

    Комментарий:

18. S15: таймер и конец помодоро. Во время фокуса левое ухо свёрнутого island показывает кольцо и синий «mm:ss» перед сводкой сессий; в шапке пульта — крупное «mm:ss», «Помодоро k из 4 · до перерыва», прогресс-бар, «Пауза» (затем «Продолжить») и «Стоп» (завершает без итогов и без перерыва); в карточке задачи — блок таймера с «Остановить». Перезапуск приложения не теряет активное помодоро. По истечении времени island сам открывает карточку «Помодоро k из 4 готов» с KPI «Ты в задаче», «Claude работал», «Отвлечения», блоком «Пока шёл таймер» (если есть данные) и полем «Перед перерывом: следующий шаг» (сохраняется в «Где остановился»). Кнопки: «Закончить на сегодня», «Ещё N без перерыва», «Перерыв M мин». В сводке дня («Сегодня») есть «Помодоро: N».

    ⬜ не проверено

    Комментарий:

19. S16: перерыв. После «Перерыв M мин» левое ухо показывает зелёное «Перерыв m:ss»; уход в Telegram/YouTube не вызывает nudge и не пишет эпизод отвлечения, карточки «Что дальше?» и «Забытые сессии» не показываются. По окончании перерыва island открывается карточкой «Перерыв окончен»: «Вернуться к «<задача>»», «Следующий шаг» (заметка из предыдущего помодоро), «Пока отдыхал: Claude закончил «<сессия>»». «Ещё 5 мин» продлевает перерыв, «Без таймера» закрывает карточку без нового помодоро, «Перейти и начать N» переключает в терминал сессии задачи и запускает новое помодоро.

    ⬜ не проверено

    Комментарий:

20. S17: выбор из «В работе». Закрытый остров без фокусной задачи → «Выбрать задачу». Карточка: «В работе · N» со строками (название, проект, «N сессий · состояние» или оранжевое «нет сессий — добавишь следующим шагом»), primary «Взять» у первой строки с сессиями; «Todo · N» свёрнут в «A · B · ещё N» с «Показать» (при пустом «В работе» развёрнут сразу, внизу «Пусто в работе — сразу список Todo»). «Взять» задачу с сессиями делает её фокусной и показывает пульт. «Взять» задачу без сессий открывает экран «Сессии задачи» (S19).

    ⬜ не проверено

    Комментарий:

21. S18: пульт задачи. В шапке «В фокусе», название и «Сменить» (открывает выбор). Сверху блок «Сессии задачи · N»: сессия, в которую перешёл последней, обведена и подписана «ты здесь», у ждущей primary «Перейти», у отложенных «Вернуть»; у каждой — «Отвязать»; без сессий — «Нет сессий — открой Claude Code и добавь сессию сюда». Под списком «+ Добавить сессию» (primary, если сессий нет), «Таймер N мин» (скрыт, пока идёт помодоро), «✓ Закрыть задачу». «Другие сессии» и «На паузе» не показываются, пока задача в фокусе; запросы разрешений чужих сессий всплывают как раньше. «Перейти» в сессию другой задачи и новые промпты в чужих сессиях не меняют фокусную задачу.

    ⬜ не проверено

    Комментарий:
22. S19: экран «Сессии задачи». Входы: «Взять» задачу без сессий, «+ Добавить сессию» в пульте, «+ Добавить сессию» в карточке задачи на доске (листом). Шапка «‹ Назад», «Сессии задачи», название и проект. «Привязаны · N» (отмечены; если нет — «Пока ни одной — отметь ниже»), «Открытые · проект X» (непривязанные отмечены), «Открытые · другие проекты»; справа «без задачи» или оранжевое «у задачи «X»» (не отмечена). Кнопка «Добавить N»; сняли галочку у привязанной — «Сохранить»; без изменений неактивна. «Позже»/«Отмена» и «‹ Назад» ничего не меняют. После «Добавить» остров возвращается в пульт задачи (без перехода в сессию), доска — в карточку.
23. S20: «Закрыть задачу». В пульте «✓ Закрыть задачу» → задача в Done, помодоро задачи остановлен, фокус снят; сверху ««X» закрыта · перенесена в Done» с «Вернуть» (8 секунд), ниже выбор задачи (если в работе или Todo что-то есть). «Вернуть» возвращает задачу в In progress первой и в фокус. В карточке задачи на доске «Закрыть задачу» (нет у задач в Done) сохраняет правки текста, переносит задачу в Done и закрывает карточку; выбор задачи в острове не открывается.
24. S21: длительности. Свежая установка или старые 25/5 → в настройках «Фокус 50 мин», «Перерыв 10 мин». В пульте «Таймер 50 мин ▾»: 25 / 50 · по умолчанию / 90 / «Своё…» (степпер, «Начать N мин»). Пока таймер идёт — только «Пауза» и «Стоп». В листе «Начать задачу» сегменты «Без таймера / 25 / 50 / 90 / Своё…», выбрано 50. На карточке «Помодоро готов» клик по «Перерыв 10 мин» запускает перерыв, меню даёт 5/10/15/20; «Ещё 50 без перерыва ▾» — 25/50/90.
25. S22: включить фокус. Перезапуск приложения при задачах в работе → остров сам открывает «Над чем работаешь сейчас?», в пульте шапка «Задача · Не выбрана» и карточка «Чтобы начать фокус, выбери задачу». После «Взять» — карточка «Фокус не идёт» с «▶ Начать фокус · 50 мин» и сегментами 25/50/90/Своё; Enter запускает. Идущий фокус — кольцо, крупное время, «Фокус 1 из 4 · из 50 мин · потом перерыв 10 мин», «Пауза»/«Стоп». Свёрнутый остров без таймера — справа «▶ Фокус 50», клик стартует фокус. «Доска» или ⌥⌘B — остров сворачивается и не перекрывает доску.
26. S23: «Ждут вне задачи». Задача в фокусе, сессия другой задачи (или без задачи) ждёт дольше порога → в пульте под сессиями задачи оранжевая кнопка «Ждут вне задачи · N ▸» (серая, пока идёт фокус). Клик раскрывает список под сессиями задачи: «Claude в этих сессиях закончил и ждёт тебя. Они не относятся к «X»», строки с возрастом («5 ч»), проектом и «у задачи «Y»»/«без задачи», «Перейти» (фокус не меняется) и «⋯»: «Добавить в «X»», «Отложить — на паузу»; внизу «Отложить все», сверху «Свернуть». В свёрнутом острове слева «N ждут» (во время фокуса — серая цифра рядом с таймером); клик по левой половине пилюли открывает пульт с раскрытым списком. Без задачи в фокусе кнопки нет — пульт и так показывает все сессии.
27. S24: без задачи — без шума. Перезапуск → остров открывается без карточки: шапка «Задача · Не выбрана» и список «Над чем работаешь сейчас?»; нет строки SESSIONS, «N сессий · держишь K», групп сессий и футера «Сегодня…». Новая сессия в Claude Code → остров сам не открывается, справа «✦ Новая сессия · задача?»; клик открывает «Над какой задачей работаешь?», выбор задачи привязывает сессию и берёт её в фокус.
28. S25: перерыв сам. Фокус (поставь 5 мин в «Своё») закончился → звук, остров открыт, «Перерыв 10 мин начнётся через 5 с», кольцо тикает; смена 5/10/15/20 не сбрасывает отсчёт; через 5 с идёт перерыв выбранной длины. В свёрнутом острове — «☕ Перерыв через N». «Отменить» → кнопка «☕ Начать перерыв · 10 мин», пилюля «☕ Перерыв 10». Перерыв идёт: «Перерыв · из 10 мин · потом фокус 50 мин», «Закончить перерыв» → «Перерыв окончен» с «▶ Начать фокус · 50 мин», сегментами, «Без таймера», «Ещё 5 мин отдыха»; пилюля «▶ Фокус 50». Выключи в настройках «Начинать перерыв автоматически» → отсчёта и звука нет.
29. S26: новая сессия в фокусе. Задача в фокусе, открываешь новую сессию → остров сам не открывается; в пульте внизу пунктирная строка «✦ Новая сессия · <проект> · «промпт»»; «В эту задачу» привязывает к задаче в фокусе, «✕» убирает строку без привязки. Наверху пульта нет строки SESSIONS и карточки выбора.

30. S27: «Перейти» в сессию Claude.app (вкладка Code). Сессия запущена в приложении Claude → «Перейти» открывает Claude именно на этой сессии (диплинк `claude://code/continue?session=local_…`), а не на последней открытой. Сессия в архиве или не найдена — Claude просто выходит на передний план, как раньше.
31. S28: итог вместо ответа. Сессия в Claude.app закончила ход с длинным ответом (таблица) → в карточке «Claude закончил» одна строка итога Claude (как в списке сессий Claude), «Перейти», «Весь ответ ▾»; если Claude ждёт решения — «НУЖНО ОТ ТЕБЯ» и вопрос. Сессия в терминале → первое предложение ответа без таблиц и кода. «Весь ответ ▾» показывает полный ответ, «Свернуть ▴» — обратно.
32. S29: сессия готова. В пульте у сессии, где Claude закончил, «✓ Готово» → строка уходит в «Готовые · 1 ▸», сверху ««X» готова · Вернуть» (8 с), «Сессии задачи · N» уменьшилось. «Вернуть» возвращает. Новый промпт в готовой сессии — она снова в активных. «⋯» у строки: «Сессия готова», «Отвязать от задачи», «Перенести в другую задачу ▸». Все сессии готовы → «Все сессии задачи готовы» с «Закрыть задачу» / «Не сейчас». На доске в карточке задачи — то же: «✓ Готово», «⋯», секция «Готовые» с «Вернуть» / «Открыть».
