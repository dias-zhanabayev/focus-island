# Focus Island v0.1.0 — Первый релиз

Первая сборка Focus Island — компаньона для сессий Claude Code в «чёлке» Mac. Остров держит в фокусе одну задачу, её сессии и таймер, а всё остальное убирает с глаз.

## Установка

```bash
gh release download v0.1.0 -R dias-zhanabayev/focus-island -p install.sh -O - | zsh
```

Или вручную: скачать `Focus.Island.dmg`, перетащить «Focus Island» в «Программы», при первом запуске — правый клик → «Открыть». Сборка подписана локальным сертификатом, без нотаризации Apple.

## Что внутри

- **Фокус**: одна задача в фокусе, её сессии, «Ждут вне задачи», доска задач, сводка дня.
- **Таймер**: фокус 50 / перерыв 10 (25 / 50 / 90 / своё), перерыв стартует сам через 5 секунд со звуком.
- **Сессии задачи**: выбор нескольких сессий, «✓ Готово» для сессии, которая сделала своё, перенос и отвязка из меню «⋯».
- **Claude.app**: «Перейти» открывает именно нужную сессию, названия и итоги ходов берутся из Claude.
- **Тихий режим**: новая сессия не открывает остров; Claude закончил — одна строка итога вместо всего ответа.

Требуется macOS 14+, универсальная сборка (Apple Silicon и Intel).
