# Focus Island v0.2.0 — Первая задача и понятные статусы

Онбординг сразу доводит до задачи в работе, у сессий появились статусы словами, а остров больше не всплывает поверх сессии, которую ты и так видишь.

## Установка и обновление

1. Скачайте `Focus.Island.dmg` ниже — один файл для Apple Silicon и Intel.
2. Откройте DMG и перетащите **Focus Island** в «Программы». При обновлении согласитесь заменить старую версию.
3. При первом запуске нажмите на приложение правой кнопкой → «Открыть».
4. В острове под чёлкой нажмите «Подключить» — Focus Island добавит хуки Claude Code.

> [!NOTE]
> Сборка подписана локальным сертификатом, без нотаризации Apple, поэтому macOS просит подтвердить первый запуск. Если «Открыть» не появляется: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».

## Что нового

- **Первая задача**: онбординг в три шага. Остров предлагает задачу из уже запущенных сессий Claude, сам подхватывает их и папку проекта, ставит задачу «В работу» и включает фокус одной кнопкой. Если Claude ещё не запущен, первая новая сессия попадёт в задачу сама.
- **Статусы сессий**: у каждой сессии бейдж — «Работает», «Ждёт ответа», «Твой ход». Завершить сессию — кружок слева; завершённые собираются в «Завершённые». Сессии, которая ждёт разрешения, — кнопка «Ответить».
- **Тихо, когда ответ на экране**: если сессия открыта в Claude.app или в терминале, итог Claude не всплывает и остров не раскрывается — ответ сразу считается прочитанным.

## Исправления

- **Сессии Claude.app не теряют задачу**, когда Claude.app перезапускает сессию с новым ID.
- **Нет дублей сессий** после перезапуска Focus Island.
