# Focus Island v0.5.0 — Музыка в фокусе и один список сессий

Во время фокуса может играть лоу-фай с Chillify, сессии показаны одним списком, а остров помнит твой фокус между запусками и меньше отвлекает.

## Установка и обновление

1. Скачайте `Focus.Island.dmg` ниже — один файл для Apple Silicon и Intel.
2. Откройте DMG и перетащите **Focus Island** в «Программы». При обновлении согласитесь заменить старую версию.
3. При первом запуске нажмите на приложение правой кнопкой → «Открыть».
4. В острове под чёлкой нажмите «Подключить» — Focus Island добавит хуки Claude Code.

> [!NOTE]
> Сборка подписана локальным сертификатом, без нотаризации Apple, поэтому macOS просит подтвердить первый запуск. Если «Открыть» не появляется: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».

## Что нового

- **Музыка во время фокуса**: Настройки → Focus → «Музыка». Лоу-фай с chillify.me играет только пока идёт фокус, на паузе и перерыве — тишина. Жанр (Chill по умолчанию, Jazzy Cafe, Asian, Soft Indie DnB, рок, микс), отдельная громкость, на карточке таймера — пауза, следующий трек и лайк. Выключено по умолчанию, нужен интернет.
- **Один список сессий**: без групп «Твой ход» и «Закончил, проверь» — плоский список со статусом у каждой сессии, свежие сверху, 10 штук и «Показать все».
- **Остров помнит фокус**: при запуске открывается последняя задача в фокусе, а не выбор задачи.
- **Сессия, в которую пишешь, попадает в фокус**: даже если раньше была привязана к другой задаче. «Начать фокус» забирает все открытые сессии.
- **«Перейти» у агентов в tmux** с удалённым доступом открывает их в приложении Claude.
- **После перерыва** под карточкой «Перерыв окончен» видны сессии задачи, кнопка — «Продолжить фокус». Если сразу открыть сессию из списка, перерыв закрывается без таймера.

## Изменения

- Остров больше не открывается сам, когда Claude закончил: растёт синяя цифра на пилюле. Разрешения и вопросы Claude по-прежнему открывают остров.
- Убраны утренний экран «Доброе утро», раздел «Скрытые» и выбор «Над чем работаешь сейчас?» на главном экране.
- «Очистить» убирает все сессии, кроме тех, где Claude ждёт ответа.
- При автодобавлении скрыта кнопка «+ Добавить сессию». «Закрыть задачу» теперь «Завершить».

## Исправления

- Сессия больше не горит зелёным «работает» после того, как Claude закончил: остров сверяется с журналом сессии и игнорирует фоновые сигналы после ответа.
- Сессия из закрытой задачи или из скрытых снова появляется в острове, когда в ней пишешь.
- Задача в фокусе больше не теряется после перезапуска острова.
