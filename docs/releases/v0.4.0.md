# Focus Island v0.4.0 — Список сессий без лишних вопросов

Новые сессии сами попадают в список и в задачу в фокусе, фокус запускается в один клик без задачи, а пилюля под чёлкой открывает остров только по клику.

## Установка и обновление

1. Скачайте `Focus.Island.dmg` ниже — один файл для Apple Silicon и Intel.
2. Откройте DMG и перетащите **Focus Island** в «Программы». При обновлении согласитесь заменить старую версию.
3. При первом запуске нажмите на приложение правой кнопкой → «Открыть».
4. В острове под чёлкой нажмите «Подключить» — Focus Island добавит хуки Claude Code.

> [!NOTE]
> Сборка подписана локальным сертификатом, без нотаризации Apple, поэтому macOS просит подтвердить первый запуск. Если «Открыть» не появляется: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».

## Что нового

- **Новые сессии добавляются сами**: появляются в списке, а при задаче в фокусе — сразу в задаче (с кнопкой «Отвязать»). В Настройках → Сессии можно выбрать «По кнопке „Добавить“» — тогда новые сессии ждут в полоске «Новые сессии» с кнопками «Добавить» и «Добавить все».
- **Чистый старт списка**: после обновления остров один раз предложит «Перенести все» открытые сессии или «Очистить, только новые». Позже список можно очистить кнопкой «Очистить список».
- **Скрытые сессии**: убранные из списка лежат в «Скрытые · N» и возвращаются кнопкой «Вернуть». Если скрытая сессия просит разрешение или задаёт вопрос, она сама показывается в списке.
- **Фокус в один клик**: без задачи остров предлагает сразу запустить фокус — задача «Фокус · дата» создаётся сама. Сессии без задачи видны рядом со списком задач.
- **Пилюля только открывает остров**: клик больше не запускает таймер, не открывает доску и не разворачивает список ждущих сессий.
- **Полоски под чёлкой мигают**, пока Claude работает, вместо бегущей волны.

## Изменения

- Убраны карточка перегрузки «N-я сессия в задаче» и настройка «Комфортно держу параллельно» вместе с подсказкой об освободившемся слоте, надписью в шапке и пометкой в итогах дня.
- Сессии безымянных задач «Фокус · …» подписаны проектом и первым запросом, а не одинаковым названием задачи.

## Исправления

- В превью запросов больше не попадают служебные теги запланированных задач и сообщений между агентами.
