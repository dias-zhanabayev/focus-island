# Focus Island v0.3.0 — Остров по клику и честный лимит сессий

Остров можно открывать только кликом, предупреждение о перегрузке считает сессии своей задачи, а в превью промптов больше не мелькают служебные теги.

## Установка и обновление

1. Скачайте `Focus.Island.dmg` ниже — один файл для Apple Silicon и Intel.
2. Откройте DMG и перетащите **Focus Island** в «Программы». При обновлении согласитесь заменить старую версию.
3. При первом запуске нажмите на приложение правой кнопкой → «Открыть».
4. В острове под чёлкой нажмите «Подключить» — Focus Island добавит хуки Claude Code.

> [!NOTE]
> Сборка подписана локальным сертификатом, без нотаризации Apple, поэтому macOS просит подтвердить первый запуск. Если «Открыть» не появляется: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».

## Что нового

- **Открытие по клику**: Settings → General → «Open island on hover». Выключите, и остров перестанет раскрываться от наведения на чёлку — только по клику. По умолчанию всё как раньше.

## Исправления

- **Перегрузка считается внутри задачи**: карточка «N-я сессия в задаче» появляется, только когда в задаче в фокусе сессий больше лимита. Сессии других задач и непривязанные больше не вызывают «Запускаешь 8-ю сессию».
- **Чистые превью промптов**: в плашке «Новая сессия», заголовках сессий и названиях задач из первого промпта больше нет служебных тегов вроде `<system-reminder>` — показывается настоящий текст.
