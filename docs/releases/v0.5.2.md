# Focus Island v0.5.2 — Агенты по имени и тихий остров

Агенты с удалённым доступом подписаны так же, как в Claude, а остров больше не открывается сам, когда Claude закончил.

## Установка и обновление

1. Скачайте `Focus.Island.dmg` ниже — один файл для Apple Silicon и Intel.
2. Откройте DMG и перетащите **Focus Island** в «Программы». При обновлении согласитесь заменить старую версию.
3. При первом запуске нажмите на приложение правой кнопкой → «Открыть».
4. В острове под чёлкой нажмите «Подключить» — Focus Island добавит хуки Claude Code.

> [!NOTE]
> Сборка подписана локальным сертификатом, без нотаризации Apple, поэтому macOS просит подтвердить первый запуск. Если «Открыть» не появляется: «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».

## Что нового

- **Агенты по имени**: агент с удалённым доступом (например, в tmux) в острове называется так же, как в Claude — `agent-product-engineer`, а не по папке и первому запросу.

## Исправления

- Остров больше не открывается сам, когда Claude закончил ответ, в том числе в сессии, где ты сейчас. О готовом ответе говорит синяя цифра на пилюле; открывают остров только запросы разрешения и вопросы Claude.
