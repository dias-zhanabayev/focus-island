# Focus Island — старт задачи и помодоро (спека)

Источник: мокапы канваса «Focus Island — экраны», страница «7 · Задача и помодоро» (7.0–7.5). Дополняет `2026-10-10-focus-island-journey-design.md`.

## Ценность

Разработчик начинает задачу одним действием, собирает к ней уже открытые сессии Claude и при желании держит фокус помодоро. Таймер привязан к задаче, а не к сессии.

## Требования

### P1. Подсказка «задача не выбрана» (7.0)
- Если `currentTask == nil` и нет алерта (тост, забытая сессия), правое ухо закрытой пилюли показывает приглушённое «Выбрать задачу · Todo N» (N = задачи в Todo). При пустом Todo — «Доска пуста».
- Клик по пилюле в этом состоянии открывает island на карточке `.pickTask` (при пустом Todo — открывает доску).
- Карточка `.pickTask`: заголовок «Над чем работаешь сейчас?», список задач Todo (тег проекта, «N сессий открыто», если к проекту задачи относятся живые сессии; такая задача первая и с primary-кнопкой), «Начать» на каждой, «+ Новая задача» (открывает доску), «Доска».
- «Начать» → P2 для этой задачи.

### P2. Старт задачи (7.1)
- Срабатывает, когда задача попадает в In progress: перетаскивание на доске, «Начать» в `.pickTask`, смена колонки в карточке задачи.
- Окно «Начать задачу» (лист в окне доски; из island — открывает доску с этим листом):
  - шапка: «Задача в работе», заголовок, проект и путь;
  - «Привязать открытые сессии»: живые сессии, сначала того же проекта (по `projectPath`/cwd). Непривязанные сессии этого проекта отмечены по умолчанию. Сессия чужой задачи помечена тегом «у задачи «X»» и не отмечена; переедет, только если отметить;
  - «Фокус-таймер · необязательно»: сегменты «Без таймера / 25 мин / 50 мин / Своё…» (своё — 5–120 мин), подпись «потом перерыв N мин»; выбор по умолчанию — из настроек (по умолчанию 25);
  - кнопки: «Новая сессия Claude» (quiet), «Позже» (закрывает, задача остаётся в In progress), «Начать · 25 мин» / «Начать» (без таймера).
- «Начать»: задача становится фокусной (`currentTask`), отмеченные сессии привязываются, при выбранном таймере стартует помодоро.

### P3. Помодоро: модель
- Фазы: `focus` и `break`. Длительность фокуса из выбора (по умолчанию `FocusSettings.pomodoroFocusMinutes` = 25), перерыва — `pomodoroBreakMinutes` = 5, цикл — `pomodoroCycle` = 4 (каждый 4-й перерыв не длиннее, просто счётчик «N из 4»).
- Пауза останавливает отсчёт; «Стоп» завершает без итогов и без перерыва.
- Хранение: таблица `pomodoros` (миграция v3): `id`, `taskId`, `phase`, `plannedSeconds`, `startedAt`, `endedAt?`, `pausedSeconds`, `completed` (досчитал до нуля). Активное помодоро переживает перезапуск приложения: при старте восстанавливается незавершённое, если оно ещё не истекло; истёкшее завершается как `completed` временем `startedAt + planned + paused`.
- Номер «N из 4» = число завершённых `focus` по задаче за сегодня + 1 (по модулю цикла).
- Если задачу удалили — помодоро останавливается.

### P4. Карточка задачи (7.2)
- Блок помодоро над колонками: кольцо прогресса, «mm:ss осталось из N мин», «Помодоро k из 4», «сегодня по задаче X мин», «Пауза/Продолжить», «Остановить». Если таймер не идёт — компактная строка «Фокус-таймер» с «Начать 25 мин» и выбором длительности.
- «Привязать сессию ▾» рядом с «Новая сессия по задаче»: поповер со списком живых сессий, не привязанных к этой задаче, сначала этого проекта; у чужих — «у задачи «X»», у непривязанных — «без задачи». Клик привязывает.

### P5. Island во время помодоро (7.3)
- Левое ухо: кольцо + «mm:ss» (синий) перед сводкой сессий; на перерыве — зелёное «Перерыв m:ss».
- Правое ухо — как раньше (задача / алерт ждущей сессии); на перерыве при работающем Claude — «Claude работает · N».
- Шапка пульта: строка таймера (крупные «mm:ss», «Помодоро k из 4 · до перерыва», прогресс-бар, «Пауза», «Стоп»).
- Футер: «Сегодня: фокус … · помодоро N · отвлечения …».

### P6. Конец помодоро (7.4)
- Карточка `.pomodoroEnd` (приоритет между nudge и returned), island открывается сам.
- «Помодоро k из 4 готов», «N минут в «задача»»; KPI за интервал помодоро: «Ты в задаче», «Claude работал», «Отвлечения» (+ «N раз, вернулся»).
- «Пока шёл таймер»: сессии задачи, у которых Claude закончил за интервал, и критерии, отмеченные за интервал (если данных нет — блок скрыт).
- Поле «Перед перерывом: следующий шаг» — сохраняется в заметку задачи («Где остановился»).
- Кнопки: «Закончить на сегодня» (quiet, без перерыва), «Ещё N без перерыва», «Перерыв M мин» (primary).

### P7. Перерыв и возврат (7.5)
- Во время перерыва: отвлечения не открывают эпизоды и не показывают nudge; карточки nextAction и stalled не показываются; пилюля как в P5.
- Конец перерыва: карточка `.breakEnd`, island открывается: «Перерыв окончен», «Вернуться к «задача»», блок «Следующий шаг» (заметка задачи), строка «Пока отдыхал: …» (сессии задачи, у которых Claude закончил за перерыв), кнопки «Ещё 5 мин», «Без таймера», «Перейти и начать N» (переход к ждущей/последней сессии задачи + новое помодоро).

### P8. Итоги
- Сводка дня: KPI-строка «Помодоро» (число завершённых focus за день) и в markdown-копии.

## Архитектура

- FocusCore: `Pomodoro` (модель), `PomodoroStore` (CRUD, сегодня по задаче), `PomodoroClock` (чистые функции: remaining, progress, isExpired, cycleIndex), миграция v3, настройки `pomodoroFocusMinutes`, `pomodoroBreakMinutes`, `pomodoroCycle`.
- `FocusCoordinator`: `pomodoro: ActivePomodoro?` (observed), `startTask(taskID:sessionIDs:focusMinutes:)`, `startPomodoro/pause/resume/stop/finishFocus/startBreak/finishBreak`, tick обновляет наблюдаемые `pomodoroRemaining`; новые карточки `.pickTask` (приоритет 1, как dayStart), `.pomodoroEnd(id)` и `.breakEnd(id)` (приоритет 6.5 → нумерация сдвигается: onboarding 10, nudge 9, pomodoroEnd/breakEnd 8, returned 7, reEntry 6, overload 5, nextAction 4, stalled 3, dayStart/pickTask 2); `pendingStartTaskID` для листа 7.1.
- UI: `StartTaskSheet`, `PomodoroBlock` (в TaskDetail), `BindSessionMenu`, `PickTaskCard`, `PomodoroEndCard`, `BreakEndCard`, таймер в шапке `SessionHubView`, уши `FocusEars`.

## Не входит
- Звуки и системные уведомления (кроме открытия island).
- Статистика помодоро в недельной сводке.

## Дополнение: выбор из «В работе» и пульт задачи (мокапы 7.0, 7.0b)

### P9. Выбор задачи из In progress
- Карточка `.pickTask`: сначала «В работе · N» — задачи In progress с кнопкой «Взять»; подпись: «N сессий · <состояние самой срочной>» или оранжевое «нет сессий — добавишь следующим шагом». Ниже «Todo · N» свёрнуто в строку («A · B · ещё N» + «Показать»); если в работе пусто — Todo развёрнут сразу. «+ Новая задача» открывает доску.
- «Взять» задачу с сессиями: задача становится фокусной (`startTask` без таймера, без листа доски), карточка закрывается, остров показывает пульт.
- «Взять» задачу из Todo: переносит в In progress и дальше как выше.
- «Взять» задачу без живых сессий: остров показывает карточку `.bindToTask(taskID)` — «Привязать открытые сессии» (галочки из `bindableSessions`, сессии чужих задач с подписью «у задачи «X»», не отмечены), кнопки «Новая сессия Claude» (quiet), «Позже», primary «Привязать N и перейти» (привязать и перейти в первую отмеченную). Подпись «Таймер — по желанию, в карточке задачи или строкой в пульте».

### P10. Пульт, когда задача в фокусе
- Шапка: «В фокусе», название задачи, рядом quiet-кнопка «Сменить» → `.pickTask`.
- Сверху блок «Сессии задачи · N» (живые сессии фокусной задачи): обведена сессия, в которой пользователь сейчас (последний переход/активный терминал с этой сессией), подпись «ты здесь»; primary «Перейти» — у ждущей сессии. Под списком: «Привязать сессию ▾», «Новая сессия по задаче», «Таймер N мин» (скрыт, если помодоро идёт — тогда строка таймера в шапке).
- Если у фокусной задачи нет живых сессий — в блоке «Нет сессий» и те же кнопки.
- Ниже «Другие сессии · N» (прежние группы без сессий задачи), «На паузе · N» свёрнуто с «Показать».

### P11. Стабильный фокус
- Явно выбранная задача (Взять, Сменить, startTask, лист доски) остаётся в фокусе, пока пользователь не сменит её явно или задача не уйдёт из In progress.
- «Перейти» в сессию другой задачи и новые промпты в чужих сессиях фокус не меняют (reEntry-карточка при переходе остаётся).
- Без явного выбора — прежнее автоматическое правило.

## Дополнение 2: сессии задачи и закрытие (мокапы 8.1–8.3)

### P12. Один экран сессий задачи
- Карточка `.bindToTask(taskID)` становится экраном «Сессии задачи» с мультивыбором. Входы: «Взять» задачу без живых сессий (как в P9), «+ Добавить сессию» в пульте, «+ Добавить сессию» в карточке задачи на доске (тот же экран листом).
- Шапка: «‹ Назад», «Сессии задачи», название и тег проекта.
- «Привязаны · N» — живые сессии задачи, отмечены. Если их нет — «Пока ни одной — отметь ниже».
- «Открытые · проект X» — живые сессии того же проекта, затем «Открытые · другие проекты». Внутри — свежие сверху. Непривязанные сессии проекта отмечены по умолчанию. Сессия чужой задачи — «у задачи «X»», не отмечена.
- Кнопка: «Добавить N» (N — новых отмеченных); если снята галочка у привязанной — «Сохранить»; без изменений — неактивна. Слева «Позже» (нет привязанных) или «Отмена».
- Применение: отмеченные привязываются, снятые отвязываются. Переход в сессию не делается — экран закрывается, остров возвращается в пульт задачи, доска — в карточку.

### P13. Пульт задачи без чужого
- Пока задача в фокусе, пульт показывает только «Сессии задачи». «Другие сессии» и «На паузе» скрыты. Карточки разрешений и вопросов чужих сессий показываются как раньше.
- У каждой сессии задачи — «Отвязать» (один клик, без подтверждения) и «Перейти».
- Под списком: «+ Добавить сессию» (primary, если сессий нет), «Таймер N мин», «✓ Закрыть задачу».
- Пустой блок: «Нет сессий — открой Claude Code и добавь сессию сюда».
- Кнопки «Новая сессия по задаче» / «Новая сессия Claude» убраны из острова, листа старта и карточки задачи.

### P14. Закрыть задачу
- «✓ Закрыть задачу» в пульте и в подвале карточки задачи: задача сразу уходит в Done (помодоро задачи останавливается), фокус снимается, сессии остаются привязанными (история и статистика).
- Остров показывает строку ««Задача» закрыта · перенесена в Done» с «Вернуть» (8 секунд); «Вернуть» возвращает задачу в In progress и в фокус. Если остров открыт и есть задачи в работе или Todo — показывается выбор задачи.
- Если закрыта задача в фокусе, фокус остаётся пустым до явного выбора («Взять», лист старта, «Вернуть»): автоматическое правило фокус не подставляет. Закрытие задачи не в фокусе фокус не меняет, и «Вернуть» для неё только возвращает её в In progress.
- Выбор другой задачи убирает строку «Вернуть». Если у закрытой задачи шло или только что истекло помодоро, оно завершается без карточки конца; её карточки помодоро и лист старта закрываются.

## Дополнение 3: длительности таймера (мокап 9.1)

### P15. 50 / 10 и где менять
- Умолчания: фокус 50 мин, перерыв 10 мин, цикл 4. Сохранённые старые умолчания 25/5 (без версии настроек) один раз переводятся в 50/10; явно выбранные значения не трогаются.
- Настройки → Focus, блок «Фокус-таймер»: «Фокус N мин» (5–120, шаг 5), «Перерыв N мин» (1–30), «Помодоро в цикле: N» (2–8), подпись «Новые значения — со следующего помодоро».
- Пульт: «Таймер N мин ▾» — меню 25 / 50 / 90 мин (у значения из настроек «· по умолчанию») и «Своё…» (поповер со степпером 5–120 и «Начать N мин»). Выбор разовый, настройки не меняет.
- Идущий таймер: только «Пауза» и «Стоп»; оставшееся время не правится.
- Лист «Начать задачу»: сегменты «Без таймера / 25 / 50 / 90 / Своё…», выбран вариант из настроек.
- Карточка конца помодоро: «Перерыв M мин ▾» и «Ещё N без перерыва ▾» — клик запускает со значением по умолчанию, меню даёт 5 / 10 / 15 / 20 и 25 / 50 / 90.

## Дополнение 4: включить фокус (мокап 10)

### P16. Фокус — это таймер
- Шапка пульта: подпись «Задача» (не «В фокусе»), без задачи — «Не выбрана».
- Под шапкой карточка фокуса:
  - задача есть, таймер не идёт — «Фокус не идёт», «▶ Начать фокус · N мин» (primary, Enter), сегменты 25 / 50 / 90 / «Своё» (поповер со степпером, «Готово»), подпись «потом перерыв M мин»; выбор сегмента разовый;
  - таймер идёт — кольцо прогресса, крупное время, «Фокус k из C · из N мин · потом перерыв M мин» (на перерыве — «Перерыв · из M мин», зелёный), «Пауза», «Стоп»;
  - задачи нет — «Чтобы начать фокус, выбери задачу», primary «Выбрать задачу».
- Кнопка «Таймер N мин ▾» из ряда действий убрана; в ряду остаются «+ Добавить сессию» и «✓ Закрыть задачу».
- Свёрнутый остров: задача есть, таймер не идёт — справа «▶ Фокус N», клик по пилюле сразу запускает фокус; без задачи — «Выбрать задачу · Todo N», «Выбрать задачу» (Todo пуст, в работе есть) или «Доска пуста».
- Запуск приложения: автоматическое правило фокуса выключено до явного выбора; если таймер не восстановлен и есть задачи в работе или Todo, остров открывает выбор задачи.
- Открытие доски (кнопка, хоткей, «Сводка дня») сворачивает остров.

## Дополнение 5: ждут вне задачи (мокап 11)

### P17. Задача всегда на виду
- Карточка `.stalled` («N сессий ждут и про них легко забыть») удалена; ждущие сессии не открывают остров. Бейдж «<задача> ждёт Nм» для запросов разрешения/вопросов остаётся.
- `waitingOutside`: при задаче в фокусе — строки `StalledPolicy.stalled` (ждёт ≥ порога из настроек, «проверь» ≥ 60 мин, без задачи ≥ 120 мин) не этой задачи; без задачи — пусто.
- Пульт: в ряду действий задачи кнопка «Ждут вне задачи · N ▸/▾» (оранжевая; серая, пока идёт фокус). Раскрывает секцию под сессиями задачи: пояснение «Claude в этих сессиях закончил и ждёт тебя. Они не относятся к «X»», строки (возраст «N м»/«N ч», название, проект, «у задачи «Y»»/«без задачи», «Перейти», меню «⋯»: «Добавить в «X»», «Отложить — на паузу»), «Отложить все», «Свернуть».
- Свёрнутый остров: слева «N ждут» с оранжевым кольцом; во время фокуса — серая цифра после таймера. Клик по левой половине пилюли открывает пульт с раскрытой секцией.

## Дополнение 6: без задачи — без шума (мокап 12)

### P18. Пульт без задачи
- Строка «SESSIONS N total · …» над пультом убрана всегда (и без задачи, и в фокусе).
- Без задачи и без таймера пульт — только шапка «Задача · Не выбрана» (Доска, шестерёнка) и встроенный список «Над чем работаешь сейчас?» (В работе · N с «Взять», Todo свёрнут, «+ Новая задача»). Нет «N сессий · держишь K», групп сессий, футера «Сегодня…» и карточки «Выбрать задачу».
- Запуск приложения: фокус не восстанавливается автоматически, остров открывается без карточки — сразу этот список.
- Новая сессия без задачи в фокусе: остров сам не открывается; справа в пилюле «✦ Новая сессия · задача?», клик открывает остров с карточкой «Над какой задачей работаешь?». Выбор задачи там привязывает сессию и берёт задачу в фокус («Новая задача из первого промпта» — тоже).
- Остров открывается по завершению сессии только если она принадлежит задаче в фокусе. Запросы разрешений и вопросы всплывают всегда.

## Дополнение 7: перерыв сам (мокап 13)

### P19. Отсчёт 5 секунд
- Фокус закончился → карточка «Фокус k из C готов», звук «Glass» и отсчёт 5 секунд, затем перерыв стартует сам (длительность — выбранная на карточке или из настроек). Отсчёт идёт, только если конец фокуса свежий (< 60 с).
- Зелёная карточка перерыва: кольцо с секундами, «Перерыв M мин начнётся через N с», «Отдохни — подсказки и отвлечения на перерыве молчат», «Начать сейчас» (Enter), «Отменить»; «Длительность» 5 / 10 / 15 / 20 (выбор не сбрасывает отсчёт), «потом фокус N мин»; поле «Следующий шаг — чтобы вернуться без раскачки». Ниже KPI и «Пока шёл таймер»; внизу «Закончить на сегодня» и «Без перерыва — ещё N мин».
- «Отменить» останавливает отсчёт, кнопка становится «☕ Начать перерыв · M мин». Следующий шаг сохраняется и при автостарте.
- Пилюля: во время отсчёта «☕ Перерыв через N», после отмены «☕ Перерыв M».
- Настройки → «Фокус-таймер»: «Начинать перерыв автоматически» и «Звук начала перерыва» (оба включены по умолчанию; звук неактивен без автоперерыва).
- Перерыв идёт: зелёная карточка-таймер «Перерыв · из M мин · потом фокус N мин» с единственной кнопкой «Закончить перерыв» (сразу карточка «Перерыв окончен»).
- Перерыв окончен: синяя карточка «▶ Начать фокус · N мин» (Enter), сегменты 25 / 50 / 90 / Своё, «Следующий шаг · …», «Перейду в сессию задачи, где Claude ждёт тебя»; внизу «Без таймера» и «Ещё 5 мин отдыха». Фокус после перерыва сам не стартует. Пилюля — «▶ Фокус N», клик запускает фокус.

## Дополнение 8: новая сессия в фокусе (мокап 14)

### P20. Тихая строка
- В фокусе новая сессия не открывает остров и не показывает большую карточку выбора задачи.
- Внизу пульта пунктирная строка «✦ Новая сессия · <проект> · «<первый промпт>»» с «В эту задачу» (привязать к задаче в фокусе) и «✕» (оставить без задачи, строка исчезает). Несколько новых сессий — по одной, следующая после ответа на предыдущую.

## Дополнение 10: сессия готова (мокап 16)

### P22. Третий исход для сессии
- `sessions.doneAt` (миграция v5). «Готово» ставит `doneAt` и снимает паузу; «Вернуть» сбрасывает. Новый промпт в сессии сбрасывает `doneAt` — сессия сама возвращается в активные.
- `HubGroup.done` (только у сессий с задачей): «Готово». `isSettled` = на паузе или готова; такие не считаются в перегрузку, свободный слот, «ждут вне задачи», подсказки «что дальше».
- Пульт: «Сессии задачи · N» — только активные. У строк, где Claude закончил ход («твой ход» / «готово, проверь»), кнопка «✓ Готово»; у всех — меню «⋯»: «✓ Сессия готова», «Отвязать от задачи», «Перенести в другую задачу ▸» (In progress и Todo). Кнопки «Отвязать» на строке больше нет.
- После «Готово»: плашка ««X» готова · Вернуть» на 8 с, строка в свёрнутой секции «Готовые · N ▸» (раскрыть: ✓, название, итог Claude, «Вернуть», «Открыть»).
- Активных нет, готовые есть → карточка «Все сессии задачи готовы» с «✓ Закрыть задачу» и «Не сейчас» (скрыта, пока число готовых не изменится).
- Карточка задачи на доске: «✓ Готово» у живых строк с законченным ходом и у прошлых; меню «⋯» вместо «Отвязать»; секция «Готовые · N» с длительностью сессии.
