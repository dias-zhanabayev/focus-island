# Focus Island

**Focus Island** — это инструмент для macOS, который превращает время ожидания Claude Code в полезное действие. Пока Claude выполняет задачу, приложение предлагает вам следующий шаг: новую задачу с простой канбан-доски, ждущую сессию или напоминает вернуться на работу, если вы отвлеклись на соцсети.

## Что умеет

**Начало дня и привязка сессии к задаче**
- «Начало дня» — утренняя карточка: что осталось открытым вчера, заметка с вечера, выбор 1–3 задач на сегодня.
- Новая сессия Claude Code предлагает привязать её к задаче (из этого проекта или других), создать задачу из первого промпта или пропустить.

**Пока Claude работает**
- Любая сессия подписана задачей и шагом плана Claude (из TodoWrite): «Шаг k из n», прогресс и оценка времени.
- «Что дальше?» — остаться в задаче: поставить в очередь следующий промпт, проверить изменённые файлы (git diff), отметить критерий готовности; вторым вариантом — переключиться на ждущую сессию или другую задачу.
- Очередь промптов: когда Claude закончит, «Отправить и вернуться» вставит промпт в терминал сессии и вернёт вас в него. Отправка в Ghostty, iTerm2, Terminal.app и tmux; в остальных терминалах промпт копируется в буфер обмена (⌘V).
- Nudge против отвлечения: если вы ушли в Telegram, YouTube и т.п., остров напомнит вернуться в терминал (отложить на 5 минут или «Мне это нужно»).
- Возврат: когда Claude закончил, карточка показывает, что сделано, критерий готовности и промпт в очереди.

**Несколько сессий**
- Пульт сессий: «Ждут тебя», «Готово, проверь», «Работают», «Без задачи», «На паузе».
- Перегрузка: при сессиях сверх лимита остров предлагает сначала ответить ждущей или поставить работающую на паузу.
- Забытые сессии: напоминание о сессиях, которые ждут дольше порога; «Отложить всё до завтра».
- Повторный вход: при переходе в другую задачу — короткая сводка «где остановился» и «что сделал Claude».
- Уши свёрнутого острова: слева сводка (работают, ждут, готово), справа задача в фокусе; оранжевый «ждёт Nм» при долгом ожидании.

**Доска и карточка задачи** (⌥⌘B)
- Канбан Backlog → Todo → In progress → Done с drag & drop; бейджи прогресса, критерия и «промпт в очереди».
- Карточка задачи: описание, критерий готовности, «Где остановился», промпт в очереди, все сессии задачи с «Перейти» / «Продолжить», «Новая сессия по задаче».

**Итоги**
- «Сегодня» — сводка дня: «Ты в работе», «Claude работал», «Сессии ждали тебя», отвлечения, лента времени по задачам, «Сделано», «Осталось открытым», «Завтра начать с»; «Скопировать в заметку» кладёт markdown-сводку в буфер.
- «Неделя» — задачи, сессии, отвлечения, часы по дням и «Куда ушло время».
- «История» — архив сессий с поиском; «Перейти» в живую и «Продолжить» через `claude --resume`.

**Настройки** (Settings → Focus)
- Статус и путь хуков Claude Code, установка и удаление.
- «Сессии»: лимит параллельных (1–6), напоминание о ждущей сессии (5–60 мин), утренний экран «Начало дня».
- «Что дальше?», «Отвлечения» (порог, стоп-лист доменов и приложений), терминал для Resume, хоткей доски.

## Сборка и запуск dev-версии

```bash
zsh scripts/launch-dev-app.sh
```

Хуки для интеграции с Claude Code устанавливаются из меню Settings → Setup. Установка хуков модифицирует `~/.claude/settings.json`.

Данные приложения хранятся в `~/Library/Application Support/FocusIsland/`.

## О проекте

Focus Island — это форк проекта [open-vibe-island](https://github.com/Octane0411/open-vibe-island) (GPL v3), адаптированный специально для Claude Code. Разработан как личный инструмент для повышения продуктивности при работе с Claude Code в терминале macOS 14+.

## Поддерживаемые терминалы

Terminal.app, iTerm2, Ghostty, tmux, Zellij, WezTerm, Warp, cmux, VS Code, Cursor, Windsurf, Trae, Qoder, CodeBuddy, JetBrains IDE (jump-to-terminal для сессий Claude Code).

## Требования

macOS 14+, Swift 6.2 toolchain / Command Line Tools. Тесты запускаются через `zsh scripts/test-clt.sh`.
