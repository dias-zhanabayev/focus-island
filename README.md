# Focus Island

[![Focus Island: один помодоро, три сессии Claude Code в Ghostty, Claude и PyCharm](docs/media/focus-island-demo.gif)](docs/media/focus-island-demo.mp4)

**Focus Island** — это инструмент для macOS, который превращает время ожидания Claude Code в полезное действие. Пока Claude выполняет задачу, приложение предлагает вам следующий шаг: новую задачу с простой канбан-доски, ждущую сессию или напоминает вернуться на работу, если вы отвлеклись на соцсети.

## Что умеет

**Начало дня и привязка сессии к задаче**
- «Начало дня» — утренняя карточка: что осталось открытым вчера, заметка с вечера, выбор 1–3 задач на сегодня.
- Новая сессия Claude Code предлагает привязать её к задаче (из этого проекта или других), создать задачу из первого промпта или пропустить.

**Фокус-таймер**
- «Выбрать задачу · Todo N» в закрытом острове и карточка «Над чем работаешь сейчас?»; старт задачи (перетаскивание в In progress или «Начать») открывает лист «Начать задачу».
- В листе привязываются открытые сессии (сначала того же проекта) и по желанию включается помодоро: 25 мин, 50 мин или своё время (5–120), потом перерыв.
- Таймер в левом ухе острова и в шапке пульта, пауза и стоп; в карточке задачи — тот же таймер и «+ Добавить сессию».
- По умолчанию 50 минут фокуса и 10 отдыха (Настройки → Focus → «Фокус-таймер»); разово — «Таймер 50 мин ▾» в пульте (25/50/90/своё) и меню длительности перерыва на карточке «Помодоро готов».
- Конец фокуса: звук и отсчёт 5 секунд, потом перерыв стартует сам (5/10/15/20 мин, можно отменить или начать сразу; отключается в настройках); KPI интервала и следующий шаг в заметку задачи. После перерыва — «▶ Начать фокус · N мин», фокус сам не стартует.
- Сессия сделала своё — «✓ Готово»: остаётся в задаче (время, итог), но уходит в свёрнутые «Готовые» и не шумит; «Вернуть» или новый промпт возвращают её. «Отвязать» и «Перенести в другую задачу» — в меню «⋯».
- Claude закончил — в острове короткий итог (у сессий Claude.app — саммари хода от самого Claude, у терминальных — первое предложение ответа), полный ответ по «Весь ответ ▾».
- Без задачи остров показывает только выбор задачи; новая сессия не открывает остров — подсказка в пилюле, а в фокусе — тихая строка «В эту задачу / ✕» внизу пульта.
- Число помодоро за день — в сводке «Сегодня».
- «Взять» в карточке выбора берёт задачу из «В работе» в фокус; без сессий сразу открывается экран «Сессии задачи» с галочками (привязанные сверху, затем сессии проекта). Пока задача в фокусе, пульт показывает только её сессии: «Отвязать», «+ Добавить сессию», «Таймер», «✓ Закрыть задачу» (сразу в Done, «Вернуть» 8 секунд).

**Пока Claude работает**
- Любая сессия подписана задачей и шагом плана Claude (из TodoWrite): «Шаг k из n», прогресс и оценка времени.
- «Что дальше?» — остаться в задаче: поставить в очередь следующий промпт, проверить изменённые файлы (git diff), отметить критерий готовности; вторым вариантом — переключиться на ждущую сессию или другую задачу.
- Очередь промптов: когда Claude закончит, «Отправить и вернуться» вставит промпт в терминал сессии и вернёт вас в него. Отправка в Ghostty, iTerm2, Terminal.app и tmux; в остальных терминалах промпт копируется в буфер обмена (⌘V).
- Nudge против отвлечения: если вы ушли в Telegram, YouTube и т.п., остров напомнит вернуться в терминал (отложить на 5 минут или «Мне это нужно»).
- Возврат: когда Claude закончил, карточка показывает, что сделано, критерий готовности и промпт в очереди.

**Несколько сессий**
- Пульт сессий: «Ждут тебя», «Готово, проверь», «Работают», «Без задачи», «На паузе».
- Перегрузка: при сессиях сверх лимита остров предлагает сначала ответить ждущей или поставить работающую на паузу.
- Ждущие сессии других задач: в пульте кнопка «Ждут вне задачи · N» раскрывает список (возраст, чья сессия, «Перейти», «⋯» — добавить в текущую задачу или отложить); остров из-за них сам не открывается, слева в пилюле тихий счётчик «N ждут».
- Повторный вход: при переходе в другую задачу — короткая сводка «где остановился» и «что сделал Claude».
- Уши свёрнутого острова: слева сводка (работают, ждут, готово), справа задача в фокусе; оранжевый «ждёт Nм» при долгом ожидании.

**Доска и карточка задачи** (⌥⌘B)
- Канбан Backlog → Todo → In progress → Done с drag & drop; бейджи прогресса, критерия и «промпт в очереди».
- Карточка задачи: описание, критерий готовности, «Где остановился», промпт в очереди, все сессии задачи с «Перейти» / «Продолжить» / «Отвязать», «+ Добавить сессию» (тот же экран выбора), «Закрыть задачу».

**Итоги**
- «Сегодня» — сводка дня: «Ты в работе», «Claude работал», «Сессии ждали тебя», отвлечения, лента времени по задачам, «Сделано», «Осталось открытым», «Завтра начать с»; «Скопировать в заметку» кладёт markdown-сводку в буфер.
- «Неделя» — задачи, сессии, отвлечения, часы по дням и «Куда ушло время».
- «История» — архив сессий с поиском; «Перейти» в живую и «Продолжить» через `claude --resume`.

**Настройки** (Settings → Focus)
- Статус и путь хуков Claude Code, установка и удаление.
- «Сессии»: лимит параллельных (1–6), напоминание о ждущей сессии (5–60 мин), утренний экран «Начало дня».
- «Что дальше?», «Отвлечения» (порог, стоп-лист доменов и приложений), терминал для Resume, хоткей доски.

## Установка

Нужен [GitHub CLI](https://cli.github.com) с доступом к репозиторию (`brew install gh && gh auth login`). Одна команда ставит последний релиз в `/Applications` и запускает его; повторный запуск обновляет:

```bash
gh release download -R dias-zhanabayev/focus-island -p install.sh -O - | zsh
```

Вручную: на странице [Releases](https://github.com/dias-zhanabayev/focus-island/releases) скачать `Focus.Island.dmg` (универсальный: Apple Silicon и Intel), перетащить «Focus Island» в «Программы», при первом запуске — правый клик → «Открыть» (сборка подписана локальным сертификатом, без нотаризации Apple).

После первого запуска: Settings → Setup → установить хуки Claude Code.

## Выпуск релиза

```bash
zsh scripts/release.sh 0.2.0
```

Нужны: чистая `main`, совпадающая с `origin/main`, заметки `docs/releases/v0.2.0.md` (первая строка — заголовок релиза) и сертификат из `zsh scripts/setup-dev-signing.sh`. Скрипт прогоняет тесты, собирает универсальный подписанный DMG и ZIP, ставит тег `v0.2.0` и публикует GitHub Release вместе с `install.sh`.

## Сборка и запуск dev-версии

```bash
zsh scripts/launch-dev-app.sh
```

Хуки для интеграции с Claude Code устанавливаются из меню Settings → Setup. Установка хуков модифицирует `~/.claude/settings.json`.

Данные приложения хранятся в `~/Library/Application Support/FocusIsland/`.

Проверки: `zsh scripts/harness.sh ci`, тесты: `zsh scripts/test-clt.sh`. Документация — [docs/index.md](docs/index.md).

## О проекте

Focus Island — это форк проекта [open-vibe-island](https://github.com/Octane0411/open-vibe-island) (GPL v3), адаптированный специально для Claude Code. Разработан как личный инструмент для повышения продуктивности при работе с Claude Code в терминале macOS 14+.

## Поддерживаемые терминалы

Terminal.app, iTerm2, Ghostty, tmux, Zellij, WezTerm, Warp, cmux, VS Code, Cursor, Windsurf, Trae, Qoder, CodeBuddy, JetBrains IDE (jump-to-terminal для сессий Claude Code).

## Требования

macOS 14+, Swift 6.2 toolchain / Command Line Tools. Тесты запускаются через `zsh scripts/test-clt.sh`.
